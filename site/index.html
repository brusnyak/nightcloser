How the test works

Two minutes. No sign-up, nothing to install.

1Tap and sendWhatsApp opens with the first message already written.
2Say what you sellOne sentence, or send your website address. With no price list it uses sample items and labels them.
3Play the customerAsk what your real customers ask. Judge the answers yourself.

What it does today

  • Replies in a few seconds, in the customer's languageAny hour. It answers in the language the customer writes in.
  • Asks one question at a timeShort messages, the way a person writes on WhatsApp.
  • Uses the prices you give itThe ones you type, or the ones on the website address you send. With neither, it uses sample items and says so.
  • Offers a 15-minute call onceWhen the customer shows they want to buy, it sends the call link one time.
  • Follows up twice, then stopsIf the customer goes quiet it writes again after 3 hours and after 20 hours. The second message carries the call link. It stops when asked.
  • Steps back when a person is neededOn refunds, complaints or a request for a person, it stops selling and flags the chat to you.

Honest limits

  • This is a test line, not a live shop. Nothing is booked, paid or stored as an order.
  • If you send a website address it reads the page text (not social pages, not logins). It can miss things, so check anything it quotes.
  • If your team already answers every message within minutes, you probably do not need it.
  • It is a language model and can make mistakes. Check what it says before relying on it.

Questions

Is it a real person?

No. It is an AI agent and says so. A person takes over when the topic needs one.

What does it cost?

The test is free. If it fits your business, we scope it together and quote before anything starts.

What happens to my messages?

They are sent to an AI model to write the replies. Do not type personal or confidential data. The chats are not published.

Does it work in Slovak?

It answers in the language you write in. English and Slovak were tested; other languages may be rougher.

Which number is this?

A dedicated test number, +421 900 000 000. It only replies to chats that start with the pre-filled message.
